Zone compliance check
Checks whether the vessel is inside a MARPOL special area and reads either the new final response schema (evaluation_type, annex_summary, disposal_assessment, rules_checklist) or the older schema (distance_to_nearest_land_nm, zone_status, active_zones, discharge_checklist, summary).
Use this flow for the general business problem: determine whether the ship is inside any MARPOL special area, whether the 12 NM nearest-land threshold is met, and what kinds of disposal are operationally allowed or restricted at the current position.
Live position map
The ship marker updates from your form inputs and from API-driven actions so the operator can see exactly where the assessment is happening.
Slop discharge check
Runs the Annex I slop checker and binds the interface to either the newer unified schema or your older slop-style response shape. The UI renders special-area status, nearest-land distance, rule checklist items, and an overall permitted or not-permitted decision.
This route is specifically for slop or oil mixed water disposal logic. It highlights whether the ship is inside an Annex I special area, whether it is beyond 12 NM from nearest land, and whether the operational rule set passes.
Live position map
Displays the ship's live reported position for the slop / oil-mixed water discharge check, so operators can visually confirm exactly where the discharge decision applies.

Route/course validation
Checks whether the ship's current coordinates lie on the route between an origin and destination port. Use this to reject invalid positions that fall far away from the intended course, such as inland coordinates or sea coordinates in the wrong region.
Example: if a vessel is travelling from Visakhapatnam to Singapore, then coordinates near that route should be valid, while coordinates like Delhi or Hyderabad should be rejected as off-route.
Route validation map
Displays origin, destination, planned route line, and the ship's reported position so operators can visually confirm whether the vessel is on the intended course.
Request history
